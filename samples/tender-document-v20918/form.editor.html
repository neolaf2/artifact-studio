招标文件 · 编辑入口

同一套 AST（data.json + data.schema.json + ontology.md）支持两条编辑路线：

VS Code / Cursor

  1. 安装 Artifact Studio 扩展
  2. 打开本目录的 data.json → Artifact AST Editor
  3. 命令面板：Render HTML / Render PDF

Web（Next.js）

  1. cd web && npm run dev
  2. 打开 /artifacts/tender
  3. 在 /settings 配置 LLM API Key（可选）

独立静态演示页：web/index.html（需 HTTP 服务）。
