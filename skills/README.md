# Skills

Agent playbooks that generate artifacts with the **local Typst (+ optional Pandoc)** toolchain. Each folder is a self-contained skill (`SKILL.md`, templates, scripts).

| Skill | Description |
|-------|-------------|
| [`bid-clarification-letter`](./bid-clarification-letter/) | Supplier clarification letter |
| [`bid-document-intelligent-review-report`](./bid-document-intelligent-review-report/) | Intelligent bid / tender review report |
| [`portable-typst-pdf-generator`](./portable-typst-pdf-generator/) | Portable Typst→PDF project bootstrap |
| [`portable-html-form-renderer`](./portable-html-form-renderer/) | HTML display/editor twin of Typst data + schema |
| [`rfp-project-document-suite`](./rfp-project-document-suite/) | Multi-document RFP suite |
| [`artifact-llm-generator`](./artifact-llm-generator/) | LLM generate/refine A-box field or whole artifact vs T-box |
| [`artifact-import-from-document`](./artifact-import-from-document/) | Import PDF/DOCX → extract → LLM-map complete A-box vs T-box |
| [`typst-showcase`](./typst-showcase/) | Typst layout demos |

Python `.venv` directories are not committed. Recreate from each skill’s docs if needed.
