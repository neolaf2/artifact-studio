# Skills

Agent / application skills that generate artifacts with the **local Typst (+ optional Pandoc)** toolchain. Each folder is a self-contained skill (`SKILL.md`, templates, scripts).

| Skill | Description |
|-------|-------------|
| [`bid-clarification-letter`](./bid-clarification-letter/) | Supplier clarification letter |
| [`bid-document-intelligent-review-report`](./bid-document-intelligent-review-report/) | Intelligent bid/tender review report |
| [`portable-typst-pdf-generator`](./portable-typst-pdf-generator/) | Portable Typst→PDF project bootstrap |
| [`rfp-project-document-suite`](./rfp-project-document-suite/) | Multi-document RFP suite (10 layouts) |
| [`typst-showcase`](./typst-showcase/) | Typst layout demos |

Python `.venv` directories are not committed. Recreate from each skill’s `requirements.txt` when needed.

For **Artifact Studio recipe demos** (manifest + data + `.typ` driven by the extension/CLI), see [`../samples/`](../samples/).
