# 报告本体结构

- **来源模板：** 招标文件智能审核综合报告（模板）
- **语言：** zh-CN
- **页面：** A4 纵向

## 主体章节与组件
- **封面**：内部受控标识、报告名称、报告说明、项目元数据、生成日期
- **总体结论与问题索引**：总体结论、风险来源分布、问题索引表
- **问题详情**：审核主题、问题详情卡片
- **发布条件与整改要求**：发布处置、整改清单、签署或复核区

## 封面字段
项目名称、项目编号 / 标段、采购品类、报告编号 / 版本、审核批次、招标文件版本

## 问题索引字段
问题来源、标识、问题位置、问题概述、当前状态

## 问题详情字段
问题编号、风险来源、结论、判断依据、原文、整改建议、问题位置、当前状态

## 章节
- 1 总体结论与问题索引
- 2 问题详情
- 3 本次审核材料范围
- 签字页

## 二级章节
- 2.1 合法性审核（是否涉嫌违法、违规）
- 2.2 国家负面清单及审计关注事项
- 2.3 公司制度与管理规范
- 2.4 同一文件内部一致性核对
- 2.5 价格与商务条件
- 2.6 跨文件及采办 2.0 一致性核对

## 审核规则
系统筛查结果须经人工确认后生效；未满足发布条件时保持待审核状态。
