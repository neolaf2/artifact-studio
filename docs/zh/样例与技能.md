# 样例与技能

## samples/ — 配方示例

面向扩展与 CLI，结构轻量：清单 + 数据 + 模板。

| 目录 | 说明 |
|------|------|
| `supplier-clarification` | 中英双语澄清函 |
| `supplier-clarification-zh` | 中文澄清函（澄字〔2026〕0147号） |

```bash
node cli/artifact-studio.js \
  samples/supplier-clarification-zh/artifact-studio.json \
  clarification-zh
```

## skills/ — Agent 技能包

面向 Agent 与完整业务文档流，通常含 `SKILL.md`、`templates/`、`scripts/`，以及可选 `test-output/`。

| 目录 | 说明 |
|------|------|
| `bid-clarification-letter` | 澄清函技能（含测试产出） |
| `bid-document-intelligent-review-report` | 智能审标报告 |
| `portable-typst-pdf-generator` | Typst→PDF 可移植脚手架 |
| `rfp-project-document-suite` | 招投标多文档套件（10 布局） |
| `typst-showcase` | 版式演示 |

未提交 Python `.venv`；需要时按各技能 `requirements.txt` 自行创建。

## 如何选择

- 只想试用「数据 → PDF」配方 → 用 **samples/**  
- 要按技能剧本跑清标 / 评审 / 招标套件 → 用 **skills/**


## HTML + AST 样例（扩展 0.4+）

| 样例 | 说明 |
|------|------|
| `samples/supplier-clarification-zh` | 中文澄清函 HTML + PDF（AST 编辑器演示） |

打开 `data.json` 使用 **Artifact AST Editor**；无界面：`node scripts/e2e-clarification-ast.js samples/supplier-clarification-zh`。

技能 [`skills/portable-html-form-renderer`](../../skills/portable-html-form-renderer/) 与 Typst 共用同一套 data / schema。
