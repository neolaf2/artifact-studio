# 配方说明（artifact-studio.json）

图形界面与 CLI 共同识别 **version 1** 配方清单。

## 最小示例

```json
{
  "version": 1,
  "artifacts": [
    {
      "id": "clarification-zh",
      "template": "letter.typ",
      "data": "data.yaml",
      "output": "output/澄清函-示例.pdf"
    }
  ]
}
```

## 字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `version` | 是 | 固定为 `1` |
| `artifacts` | 是 | 非空数组 |
| `artifacts[].id` | 是 | 字母数字、`_`、`-`；同一文件内唯一 |
| `artifacts[].template` | 是 | 相对路径，`.typ` |
| `artifacts[].data` | 是 | 相对路径，`.json` / `.yaml` / `.yml` |
| `artifacts[].output` | 是 | 相对路径，`.pdf`，不得覆盖 template/data |

可选扩展字段（若样例中存在）：`ontology`、`dataSchema` 等，用于文档与校验提示，以扩展实现为准。

## 路径安全

所有相对路径必须落在配方文件所在目录（工程根）之内，禁止 `..` 逃逸。Symlink 也不得指向根外。

## 模板如何读数据

构建时核心将数据文件路径通过 Typst `--input data=/…` 传入。模板内典型写法：

```typst
#let source = sys.inputs.at("data")
#let data = if source.ends-with(".json") { json(source) } else { yaml(source) }
```

参见 `samples/supplier-clarification-zh/letter.typ`。
