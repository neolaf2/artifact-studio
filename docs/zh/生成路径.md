# 生成 PDF 的多种路径

Artifact Studio 把「数据 + Typst 模板 → PDF」做成可复用配方，并提供多种入口。底层都是本机 Typst。

## 对照表

| 路径 | 入口 | 校验配方清单 | 预览页 | 适合谁 |
|------|------|--------------|--------|--------|
| 图形界面 | VS Code / Cursor 扩展 | 是 | 是（Build and Preview） | 人工编辑 |
| CLI | `cli/artifact-studio.js` | 是 | 默认否（可调 API） | 脚本 / Agent / CI |
| Skills | `skills/*/SKILL.md` + 脚本 | 技能自定义 | 技能自定义 | 编程 Agent、完整业务文档 |
| 直接 Typst | `typst compile` | 否 | 否 | 模板调试 |
| Pandoc | `pandoc` | — | — | DOCX / MD 旁路交付 |

## 路径 1：图形界面

安装 VSIX 后打开含 `artifact-studio.json` 的文件夹，使用：

- **Build Artifact** — 写 PDF  
- **Build and Preview** — PDF + PNG 页预览  
- **Toggle Watch** — 保存自动重建  

见仓库 [README.zh-CN.md](../../README.zh-CN.md)「路径 1」。

## 路径 2：CLI

```bash
node cli/artifact-studio.js <artifact-studio.json> [artifact-id]
```

与扩展共用 `extension/src/core.js`。stdout 为 JSON，便于 Agent 解析。

## 路径 3：Skills

进入某一技能目录，阅读 `SKILL.md`，按其脚本生成。技能可包含多文件工程、测试产出、Pandoc 导出等，不限于单份 `artifact-studio.json`。

## 路径 4：直接 Typst

```bash
typst compile --root . --input data=/data.yaml letter.typ output/out.pdf
```

跳过清单校验，适合改 `.typ` 时快速试错。

## 路径 5：Pandoc

在已有 Markdown / 技能产出上导出 Word 等，不替代 Typst PDF 主路径。

## 选型建议

| 场景 | 建议 |
|------|------|
| 改澄清函措辞并看版式 | 图形界面 |
| 流水线批量出 PDF | CLI |
| 「按招标流程出一套文件」 | Skills（如 RFP 套件） |
| 只调字体与页边距 | 直接 Typst |
| 给业务同事 Word | Pandoc |
