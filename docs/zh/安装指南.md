## 环境要求（按路径）

| 组件 | 用途 | 说明 |
|------|------|------|
| **Typst**（在 `PATH` 中） | 所有 PDF 构建 | 必需 |
| **Pandoc** | DOCX/MD、部分技能 | 仅 PDF 时可省略 |
| **Cursor** 或 **VS Code** 1.95+ | 图形界面 | 用脚本装 VSIX 时需编辑器 CLI |
| **Node.js 18+** | CLI `npm link`、打包 VSIX | 仅 Typst 不需要 |
| **CJK 字体** | 中文样例 | 如苹方、Noto Sans CJK SC |
| **Homebrew**（macOS） | 脚本 `--deps` | https://brew.sh/ |
| **curl** + **xz**（Linux） | 脚本下载 Typst | 通过 apt/dnf/pacman |

## A. 一键脚本（macOS / Linux）

在仓库根目录（建议先 dry-run，再执行）：

```bash
git clone https://github.com/neolaf2/artifact-studio.git
cd artifact-studio

./scripts/install.sh                 # 规划：deps + 扩展 + CLI
./scripts/install.sh --check         # 仅检查环境
./scripts/install.sh --execute --all # 实际安装 deps + VSIX + npm link
```

### 脚本参数（覆盖各安装路径）

| 参数 | 作用 |
|------|------|
| *（默认）* | 等同 `--deps --extension --cli`（仅规划） |
| `--execute` | 真正执行（不加则只打印计划） |
| `--all` | 依赖 + 扩展 + CLI |
| `--deps` | 安装 Typst（包管理器有则一并装 Pandoc） |
| `--extension` | 将 `extension/*.vsix` 装入 Cursor 和/或 VS Code CLI |
| `--cli` | 在 `cli/` 执行 `npm link` → 命令 `artifact-studio` |
| `--skills-deps` | 运行各 `skills/*/scripts/install.sh` |
| `--check` | 只打印状态 |
| `--help` | 帮助 |

系统入口（参数相同）：

```bash
./scripts/install-macos.sh …
./scripts/install-linux.sh …
```

Windows 无上述脚本，请按下文 B–G 手动安装。

## B. 工具链（Typst + Pandoc）

### macOS（Homebrew）

```bash
brew install typst pandoc
typst --version
pandoc --version
```

或：

```bash
./scripts/install.sh --execute --deps
```

### Linux

**Typst**（官方 release 安装到 `~/.local/bin`）：

```bash
./scripts/install.sh --execute --deps
# 或手动从 https://github.com/typst/typst/releases 下载 musl 包
```

**Pandoc** 示例：

```bash
sudo apt-get install -y pandoc    # Debian/Ubuntu
sudo dnf install -y pandoc        # Fedora
sudo pacman -S pandoc             # Arch
```

### 覆盖 Typst 路径

```bash
export TYPST_PATH=/path/to/typst
```

## C. 扩展（图形界面）

**所需文件：** `extension/artifact-studio-0.2.0.vsix`（亦见 [GitHub Releases](https://github.com/neolaf2/artifact-studio/releases)）。

### C1. 安装脚本

```bash
./scripts/install.sh --execute --extension
```

### C2. 编辑器命令行

```bash
cursor --install-extension extension/artifact-studio-0.2.0.vsix
# 和/或
code --install-extension extension/artifact-studio-0.2.0.vsix
```

### C3. 编辑器界面

1. 打开 Cursor 或 VS Code  
2. 扩展视图 → `…` → **从 VSIX 安装…**  
3. 选择 `extension/artifact-studio-0.2.0.vsix`  
4. 重新加载窗口  

### 安装后

1. **文件 → 打开文件夹** → 例如 `samples/supplier-clarification-zh`  
2. 命令面板 → **Artifact Studio: Build and Preview**  

常用命令：**Build Artifact**、**Toggle Watch**、**Check Local Environment**、**New Example Project**。

## D. CLI

需要 **Node.js 18+** 与本机 **Typst**。

### D1. 免安装直接跑

```bash
node cli/artifact-studio.js \
  samples/supplier-clarification-zh/artifact-studio.json \
  clarification-zh
```

### D2. 全局链接

```bash
./scripts/install.sh --execute --cli
# 或
cd cli && npm link

artifact-studio samples/supplier-clarification/artifact-studio.json
```

标准输出为 JSON；Typst 日志在 stderr。环境变量：`TYPST_PATH`。

详见 [`cli/README.md`](../../cli/README.md)。

## E. 技能依赖

`skills/` 下技能除 Typst 外常需 Python 虚拟环境、Poppler 等。

```bash
./scripts/install.sh --skills-deps
./scripts/install.sh --execute --skills-deps
```

或单个技能：

```bash
./skills/bid-clarification-letter/scripts/install.sh --execute
./skills/bid-document-intelligent-review-report/scripts/install.sh --execute
```

随后按该技能的 `SKILL.md` 执行。

## F. 直接 Typst

不需要扩展或 CLI：

```bash
cd samples/supplier-clarification-zh
typst compile --root . --input data=/data.yaml letter.typ output/澄清函-示例.pdf
```

此路径不做配方校验；需要校验时请用 CLI 或图形界面。

---

## G. Pandoc（可选）

```bash
cd samples/supplier-clarification-zh
pandoc output/澄清函-正文.md -o output/澄清函-示例.docx
```

不替代本仓库配方的 Typst PDF，仅作 Word/Markdown 交付旁路。

## H. 源码运行扩展（F5）

```bash
cd extension
# 可选：npm install / npm test / npm run package
```

在 VS Code 或 Cursor 中打开 `extension/`，按 **F5**（**Run Artifact Studio**）。需要分发包时执行 `npm run package` 生成 VSIX。

## Artifact AST 编辑器（扩展 0.4+）

`data.json`/`data.yaml` + JSON Schema + ontology（T-box）构成上游编辑与下游 HTML/Typst 渲染的 AST。

1. 安装扩展 ≥ 0.4.0
2. 打开 `samples/supplier-clarification-html-zh/data.json`
3. 默认进入 **Artifact AST Editor**
4. 编辑后点 **Render HTML** / **Render PDF**，或运行命令 `Artifact Studio: E2E Clarification Demo`

无界面演示：`node scripts/e2e-clarification-ast.js samples/supplier-clarification-html-zh`
