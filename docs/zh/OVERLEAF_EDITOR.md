# Overleaf-style Artifact Editor (zh)

See English: [../OVERLEAF_EDITOR.md](../OVERLEAF_EDITOR.md).

## Open / New project

Web `/` dashboard:

- **Open** -> `/artifacts/[id]`
- **New project** -> name + template (`clarification` / `tender`) -> scaffold T/A/R -> durable save -> editor

API: `GET/POST /api/artifacts`.

VS Code: **Artifact Studio: Open Project**, **Artifact Studio: New Project**.

Fake org names only in demos.
