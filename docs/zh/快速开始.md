# 快速开始

## 1. 安装依赖

```bash
brew install typst
# 可选
brew install pandoc
```

确认：

```bash
typst --version
```

## 2. 获取本仓库

```bash
git clone https://github.com/neolaf2/artifact-studio.git
cd artifact-studio
```

## 3. 用 CLI 生成中文澄清函 PDF（推荐先试）

```bash
node cli/artifact-studio.js \
  samples/supplier-clarification-zh/artifact-studio.json \
  clarification-zh
```

成功时 stdout 为 JSON，PDF 写在：

`samples/supplier-clarification-zh/output/澄清函-示例.pdf`

## 4. 用图形界面预览

```bash
cursor --install-extension extension/artifact-studio-0.4.0.vsix
```

然后在 Cursor 中打开 `samples/supplier-clarification-zh`，命令面板执行 **Artifact Studio: Build and Preview**。

## 5. 改内容再生成

- 改文案 / 澄清项：编辑 `data.yaml`（或 `data.json`）
- 改版式：编辑 `letter.typ`
- 再跑 CLI 或扩展中的 Build
