# 快速开始

## 1. 安装依赖

```bash
brew install typst
# 可选
brew install pandoc
```

确认：

```bash
typst --version
```

## 2. 获取本仓库

```bash
git clone https://github.com/neolaf2/artifact-studio.git
cd artifact-studio
```

## 3. 用 CLI 生成中文澄清函 PDF（推荐先试）

```bash
node cli/artifact-studio.js \
  samples/supplier-clarification-zh/artifact-studio.json \
  clarification-zh
```

成功时 stdout 为 JSON，PDF 写在：

`samples/supplier-clarification-zh/output/澄清函-示例.pdf`

## 4. Web（Overleaf 风格）

```bash
cd web && npm install && npm run dev
```

打开 http://localhost:3000 → **打开**「供应商澄清函」或 **新建项目**。详见 [OVERLEAF_EDITOR.md](./OVERLEAF_EDITOR.md)。

## 5. 用图形界面预览（VS Code / Cursor）

```bash
# Install the newest VSIX under extension/ (package.json is 0.5.3+; rebuild if needed)
ls extension/artifact-studio-*.vsix | sort | tail -1
cursor --install-extension "$(ls extension/artifact-studio-*.vsix | sort | tail -1)"
```

然后：

- **Artifact Studio: Open Project** / **New Project**，或
- 打开 `samples/supplier-clarification-zh` 的 `data.json` → Artifact AST Editor，或
- **Artifact Studio: Build and Preview**

## 6. 改内容再生成

- 改文案 / 澄清项：编辑 `data.yaml`（或 `data.json` / A-box）
- 改版式：编辑 Typst 视图模板
- 再跑 CLI、Web 保存，或扩展中的 Build
